# Die ersten drei Tage

> **Status:** Entwurf 20.08.2026 · **Kein Forschungsbezug** · **Der arbeitsintensivste Teil der Vorbereitung**
> **Grundsatz:** Skripten heißt Minutenplan, nicht Themenliste. Nicht „Vormittag: Kennenlernen und
> Routinen", sondern welcher Satz welche Routine einleitet.

---

## Tag 1 · Montag [[DATUM_TAG1]]

| Zeit | Was | Material | Wer |
|---|---|---|---|
| vorher | An der Tür stehen, jedes Kind einzeln begrüßen, Namen sagen | Namensliste in der Hand | ich |
| 0–5 | Sitzplätze sind vorbereitet und beschriftet. Kinder finden ihren Platz | Namenskärtchen | |
| 5–15 | Begrüßung, wer ich bin, was heute passiert. Tagesablauf an der Tafel | Tafelbild vorbereitet | |
| 15–35 | Kennenlernen: Steckbrief ausfüllen, dann Partnervorstellung | Steckbriefe | |
| 35–45 | **Routine 1: Fokus-Signal.** Erklären, dreimal üben, loben | Routinenkarte | |
| 45–55 | Pause, ich stehe im Gang, nicht im Konferenzzimmer | | |
| 55–70 | **Routine 2: Basis-Start.** Einmal vormachen, dann üben lassen | Routinenkarte | |
| 70–85 | Schulhaus-Rundgang: Sekretariat, Turnsaal, WC, Direktion | | |
| 85–100 | **Routine 3: Zuhören.** Erklären, üben | Routinenkarte | |
| 100–115 | **KlassenHub, 15 Minuten**, siehe eigenes Skript | Zugangszettel | |
| 115–125 | Abschluss und Ausblick: was morgen kommt. Erste Hausübung ansagen | | |

**Der wichtigste Punkt des Tages** ist nicht der Inhalt, sondern dass jedes Kind mindestens einmal
mit Namen angesprochen wurde. Die Jahreswirksamkeit von Sek-1-Lehrkräften hängt messbar an dem,
was am ersten Tag passiert.

**Nicht am Tag 1:** Regeln, Konsequenzsystem, Klassenjobs, Sitzordnungsdiskussion.

---

## Tag 2 · Dienstag

| Zeit | Was |
|---|---|
| vorher | Wieder an der Tür. Ziel: heute alle Namen ohne Liste |
| 0–10 | Basis-Start ohne Ansage. Wenn es klappt: benennen und loben |
| 10–20 | **Routine 4: Hilfe holen** |
| 20–40 | Fachlicher Einstieg, erste richtige Arbeitsphase |
| 40–50 | **KlassenHub, 5 Minuten**: was heißt „erledigt" |
| 50–70 | Klassenidentität: Wie wollen wir miteinander umgehen? Sammeln, nicht festlegen |
| 70–85 | **Routine 5: Arbeitsphase starten** |
| 85–95 | Abschluss und Ausblick |

---

## Tag 3 · Mittwoch

| Zeit | Was |
|---|---|
| vorher | Tür. Namen sitzen |
| 0–10 | Basis-Start, kein Kommentar mehr nötig |
| 10–20 | **Routine 6: Übergang wechseln** |
| 20–45 | Fachunterricht |
| 45–55 | **KlassenHub, 5 Minuten**: Erinnerungen |
| 55–75 | Klassenidentität weiterführen, Klassenposter beginnen |
| 75–85 | **Routine 7: Material-Check** |
| 85–95 | Abschluss, Ausblick auf die erste volle Woche |
