## Teil A · Terminvergabe (an die Eltern)

**Elternsprechtag am ____________, von ______ bis ______ Uhr, Raum ____________**

Ein Gespräch dauert **zehn Minuten**. Das ist kurz, aber es ist die einzige Möglichkeit, allen
einen Termin zu geben. Wenn zehn Minuten nicht reichen, vereinbaren wir einen eigenen Termin, und
das ist kein schlechtes Zeichen.

Bitte tragen Sie sich ein:

| Uhrzeit | Kind | Uhrzeit | Kind |
|---|---|---|---|
| 15:00 | | 16:00 | |
| 15:10 | | 16:10 | |
| 15:20 | | 16:20 | |
| 15:30 | | 16:30 | |
| 15:40 | | 16:40 | |
| 15:50 | | 16:50 | |

☐ Ich kann an keinem der Termine und bitte um einen Ausweichtermin.
☐ Ich brauche eine Übersetzung. Sprache: ____________
☐ Ich möchte, dass mein Kind beim Gespräch dabei ist.

## Der Rahmen, den ich setze, wenn die Frage „Was kann ich zuhause tun?" kommt

> „Reden Sie mit Ihrem Kind über die Schule, fragen Sie nach etwas Bestimmtem statt nach ‚wie
> war's', und sagen Sie ihm, dass Sie ihm das zutrauen. Das ist der am besten belegte Hebel, den
> Eltern haben, und es ist weniger Arbeit als Kontrollieren."
