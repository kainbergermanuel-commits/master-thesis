# Beschriftungen für Box und Kuverts

> **Status:** Entwurf 20.08.2026 · **Strang C** · **Druck:** Etiketten, A4-Bogen

---

## Aufkleber für die Box

```
┌───────────────────────────────────────────────┐
│                                               │
│      RÜCKGABE  ·  MASTERARBEIT                │
│                                               │
│      Bitte alle Kuverts hier einwerfen,       │
│      auch wenn „Nein" angekreuzt ist.         │
│                                               │
│      Frist:  [[FRIST_RUECKGABE]]              │
│                                               │
│      Zuständig: [[NEUTRALE_STELLE]]           │
│      Die Kuverts werden erst nach der Frist   │
│      geöffnet.                                │
│                                               │
└───────────────────────────────────────────────┘
```

## Aufdruck für die Kuverts

**Nichts.** Die Kuverts bleiben unbeschriftet und sind untereinander nicht unterscheidbar.

Ein Aufdruck mit Name oder Klasse würde beim Einwurf sichtbar machen, wer abgibt, und damit den
ganzen Aufwand entwerten. Der Name steht **innen**, auf dem Formular.

## Ersatzkuverts

Zehn Stück in Reserve, bei [[NEUTRALE_STELLE]] **und** bei mir. Wer eines braucht, bekommt eines,
wortlos und ohne Notiz.
